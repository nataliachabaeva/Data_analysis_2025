# Учебные работы по анализу данных

В этом репозитории представлены учебные работы по курсам:  
- **«Введение в анализ данных»**  
- **«Введение в анализ данных. Дополнительные главы»**  

> В некоторых заданиях условия были частично изменены, чтобы усложнить поиск решений для будующих студентов.  
> Оригинальные условия можно найти [здесь](https://thetahat.ru/courses/ad).

## Содержимое репозитория

- **1_trees_kNN.ipynb** — простой EDA, решающие деревья, kNN.  
- **2_plotly.ipynb** — использование модуля Plotly для визуализации + EDA.  
- **3_regressions_1.ipynb** и **3_regressions_2.ipynb** — задания по линейной и логистической регрессиям. В некоторых задачах пребуется EDA,но в основном данные сгенерированы из различных распределений.
