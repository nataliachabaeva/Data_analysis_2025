# Учебные работы по анализу данных

В этом репозитории представлены учебные работы по курсам:  
- **«Введение в анализ данных»**  
- **«Введение в анализ данных. Дополнительные главы»**  

> В некоторых заданиях условия были частично изменены.
> Оригинальные условия можно найти [здесь](https://thetahat.ru/courses/ad).

## Содержимое репозитория

- **1_trees_kNN.ipynb** — простой EDA, решающие деревья, kNN.  
- **2_plotly.ipynb** — использование модуля Plotly для визуализации + EDA.  
- **3_regressions_1.ipynb** и **3_regressions_2.ipynb** — задания по линейной и логистической регрессиям. В некоторых задачах требуется EDA, но в основном данные сгенерированы из различных распределений.
- **4_CNN_basic.ipynb** и **4_CNN.ipynb** - задания по реализации и применению нейронных сетей.
- **5_CNN_CV.ipynb** - задание на классификацию MNIST с помощью сверточных нейросетей.
- **6_CNN_NLP.ipynb** и **6_NLP_usage.ipynb** - применение сверточных нейросетей для NLP задач и применение обученных LLM.
- **7_clustering.ipynb** - понижение размерности и кластеризация для изображений.
- **8_statistics.ipynb** и **9_statistics.ipynb** - проверка статистических законов, выборочная медиана, состоятельные и асимптотически нормальные оценки.
- **10_extra.ipynb** - исследование вакансий с hh.ru, кластеризация вакансий по описанию.
